🎯 Reliable decisions

Objective: turn a vague choice into a recommendation with evidence, explicit gaps, and adversarial critique.

/research /truth /gaps /pushback /rank criteria= /decide sobre

How to verify: the response must separate facts from inferences, list gaps, include a serious challenge to your idea, and end with a justified ranking and final recommendation.

🏗️ Agent architecture

Objective: specify a complete agent before writing the first line of the prompt.

/agent /tools /memory /guardrails /eval /integrate for

How to verify: you should receive an objective, tools with usage criteria, a memory policy, operational limits, test cases, and an integration plan.

🛡️ Truthfulness audit

Objective: check a text full of claims before publishing it or making a decision based on it.

/factcheck /confidence /provenance no texto:

How to verify: each claim classified (confirmed, imprecise, false, inconclusive, opinion), overall confidence level, and source of each critical data point.
